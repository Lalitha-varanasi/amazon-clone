# amazon-clone
# 🛒 Amazon Clone (HTML & CSS)

This project is a **basic Amazon homepage clone** created using **HTML and CSS only**.  
It focuses on replicating the visual layout of the Amazon landing page.

---

## 🚀 Features

- ✅ Amazon-style homepage layout
- ✅ Navigation bar with logo and search bar
- ✅ Hero/banner section
- ✅ Product category sections
- ✅ Clean UI using pure CSS

 Technologies Used

- **HTML5**
- **CSS3**

 Limitations

- ❌ Not responsive (best viewed on laptop/desktop screens)
- ❌ No JavaScript functionality
- ❌ No backend or dynamic features

- 
***project structure***
  amazon-clone/
│
├── amazon.html # Main HTML file
├── styles.css # CSS styling
└── images/ # Images used in the project
